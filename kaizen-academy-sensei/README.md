# Kaizen Academy Sensei

A Traditional AI Sensei that teaches Toyota Production System fundamentals, lean implementation tools, and kaizen methodologies based on provided PDF resources.

## Features

- 🎓 **Traditional Sensei Persona**: Wise, formal teaching from Toyota principles
- 📚 **Knowledge Base**: Built from your provided lean manufacturing PDFs
- 🎯 **Focused Topics**: TPS fundamentals, lean tools, kaizen methods
- 🔍 **Smart Search**: Keyword-based question answering with source citations
- 📖 **Source Attribution**: Every answer references specific PDFs and pages

## Current Knowledge Base

Based on the uploaded PDFs:
- Toyota Production System (Taiichi Ohno)
- The Toyota Way (Jeffrey Liker) 
- Lean Production Simplified (Dennis Pascal)
- Creating a Lean Culture (David Mann)
- Gemba Kaizen (Commonsense Approach)
- And more lean classics...

## Getting Started

1. Install dependencies: `npm install`
2. Start development: `npm run dev`
3. Build for production: `npm run build`

## Adding New Resources

### Supported Formats
- PDF files (recommended)
- EPUB
- MOBI
- TXT/Markdown

### How to Add Resources
1. Place new PDFs in `/docs` folder
2. Run the content extraction script (coming soon)
3. Restart the application

### Future Enhancement
- Automatic PDF content extraction
- Multiple ebook format support
- Dynamic knowledge base updates
- Advanced semantic search
