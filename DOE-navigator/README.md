# DOE Navigator

Design of Experiments (DOE) tool guided by Montgomery's methodology.

## Development

```bash
npm install
npm run build
```

## Deployment

This app is designed to be deployed as a standalone Vercel project.

### Vercel Configuration
- **Root Directory**: `DOE-Navigator`
- **Framework Preset**: Other
- **Build Command**: `npm run build`
- **Output Directory**: `.` (root)

## Features

- 7-stage DOE wizard methodology
- Statistical analysis engine
- Design recommendations
- ANOVA and effects analysis
- Professional reporting

## Technology Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Lucide React icons
